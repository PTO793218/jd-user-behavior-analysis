# 指标定义

## 数据概览指标

数据概览用于快速说明项目分析范围。当前主数据包含 757,554 条行为记录、10,739 名用户、327,582 件商品、5,357 个商品类目，时间范围为 2024-05-29 至 2024-06-04。

这些指标用于回答“数据规模多大”“覆盖多少用户”“分析周期是什么”等问题。

## 行为漏斗

行为漏斗用于衡量用户从浏览到购买的转化过程。当前漏斗顺序为：

```text
浏览 pv -> 加购 cart -> 收藏 fav -> 购买 buy
```

当前行为计数为：

- 浏览：679,668。
- 加购：42,714。
- 收藏：20,601。
- 购买：14,571。

主要转化率口径：

- 上一步转化率：当前阶段数量 / 上一阶段数量。
- 相对浏览转化率：当前阶段数量 / 浏览数量。

例如购买相对浏览转化率约为 `14,571 / 679,668 = 2.14%`。浏览到加购转化率约为 `42,714 / 679,668 = 6.28%`，说明大量用户停留在浏览阶段，没有进入明确购买意向阶段。

## RFM 用户分层

RFM 是用户价值分析模型：

- R：Recency，最近一次购买距离当前分析结束日的时间间隔。间隔越短，用户越近期活跃。
- F：Frequency，用户购买频次。频次越高，说明复购意愿越强。
- M：Monetary，用户消费金额。金额越高，说明商业贡献越高。

当前项目使用 R、F、M 评分组合生成用户标签。RFM 分层用于回答“哪些用户价值高”“哪些用户需要召回”“哪些用户适合重点维护”等问题。

当前人数最多的分层是核心价值用户，共 1,720 人，占 RFM 用户的约 28.16%。流失用户共 1,278 人，占约 20.92%。这说明项目既有一批高价值用户，也存在明显的召回空间。

## 时间趋势

时间趋势分为日趋势和小时趋势。

日趋势用于观察分析周期内每天的行为量、购买量和销售额变化。小时趋势用于识别一天中用户活跃高峰，辅助安排促销、优惠券推送和内容触达。

时间趋势回答的问题包括：

- 哪些时段用户最活跃？
- 促销活动适合安排在什么时候？
- 行为量是否在特定日期出现明显波动？

## 地区销售指标

地区分析使用 `address` 字段聚合，主要统计：

- 地区行为记录数。
- 地区购买次数。
- 地区销售额。

地区销售额用于识别高贡献区域，地区行为量用于识别高活跃区域。两者不一定完全一致：高活跃地区可能浏览多但购买少，高销售地区可能用户量不大但客单价或购买量较高。

## 设备转化率

设备转化分析使用 `device` 字段聚合，主要统计：

- 不同设备的行为记录数。
- 不同设备的购买记录数。
- 不同设备的转化率。

设备转化率通常按 `购买记录数 / 行为记录数` 计算，用于判断不同终端用户的购买效率差异。

## 评论关键词

评论关键词来自 `data/processed/comment_word_freq.csv`，用于快速识别评论中高频出现的词。词频分析适合发现用户常提到的主题，但不能准确判断情绪和具体原因。

例如一个词出现频率高，只能说明用户经常提到它，不能直接说明用户是满意还是不满意。因此第二版增加了评论语义分析。

## 评论语义指标

评论语义分析通过大模型对评论样本进行结构化标注，输出情绪、情感分数、方面标签和负面原因。

当前语义样本规模：

- 已分析评论样本：960 条。
- 正面：447 条。
- 负面：429 条。
- 中性：84 条。

情感分数 `sentiment_score` 的范围为 -1 到 1：

- 越接近 1，情绪越正面。
- 越接近 -1，情绪越负面。
- 接近 0，通常代表中性或倾向不明显。

方面标签固定为：质量、物流、价格、服务、包装、售后、体验。

当前负面率较高的方面包括：

- 售后：57 条相关评论，50 条负面，负面率约 87.72%。
- 服务：148 条相关评论，96 条负面，负面率约 64.86%。
- 包装：91 条相关评论，51 条负面，负面率约 56.04%。
- 质量：705 条相关评论，305 条负面，负面率约 43.26%。

解释语义分析结果时必须说明这是 960 条去重评论样本，不是全量评论。

## V6 用户路径分析

用户路径分析基于 `jd_analysis_final.csv` 的结构化全量行为数据，按 `user_id + goods_id` 聚合，统计每类行为的首次出现时间，再按首次出现时间形成路径。如果同一用户对同一商品多次浏览，只取首次浏览时间进入路径，避免重复浏览把路径拉长。

主要指标包括：

- 常见路径：同一用户对同一商品的行为序列出现次数。
- 路径转化率：该路径中包含购买行为的路径数 / 该路径总数。
- 关键流失路径：未出现购买行为、停留在浏览/加购/收藏等阶段的路径。
- 首次浏览到购买间隔：同一 `user_id + goods_id` 中首次浏览时间到首次购买时间的小时差。

用户可以问：“用户最常见的购买路径是什么？”“浏览后直接购买的人有多少？”“哪个路径流失最严重？”

## V6 类目/商品运营矩阵

运营矩阵用于比较类目或商品的流量和转化效率。流量口径为 PV，转化口径为购买数 / PV。高低阈值使用当前分析维度下的中位数：

- 高流量高转化：PV 不低于中位数，转化率不低于中位数。
- 高流量低转化：PV 不低于中位数，转化率低于中位数。
- 低流量高转化：PV 低于中位数，转化率不低于中位数。
- 低流量低转化：PV 低于中位数，转化率低于中位数。

该矩阵适合回答“哪些类目属于高流量低转化”“哪些商品应该加大曝光”“哪些类目应该优先优化详情页或价格”。它是历史静态数据诊断，不代表实时投放效果。

## V6 价格带与转化

价格带分析使用固定区间：

```text
0-50、50-100、100-200、200-500、500+
```

由于浏览、加购和收藏记录可能没有直接价格，系统会先用购买记录推断同一商品的成交价中位数，再回填到同商品的其他行为记录。核心指标包括浏览量、加购量、收藏量、购买量、销售额、购买转化率和 RFM 用户层分布。

该分析适合比较历史转化，不应解读为实时价格敏感性实验结论。

## V6 RFM 分层行为差异

RFM 行为差异分析将结构化行为数据与 `jd_rfm_result.csv` 按 `user_id` 关联，比较不同用户层在类目偏好、行为路径、加购率、购买率和价格带偏好上的差异。转化率口径仍为购买数 / PV，加购率为加购数 / PV。

该能力适合回答“核心价值用户和流失用户有什么行为差异”“高潜力用户应该怎么运营”“重点保持用户更偏好哪些商品或价格带”。

## V6 销售额预测

销售额预测基于小时级销售额聚合数据，输出未来 24 小时的销售额基线预测。当前实现至少使用移动平均或线性回归基线方法，并返回预测时间点、预测销售额和趋势判断。

必须说明：当前行为数据时间范围较短，预测只适合短期趋势辅助判断，不应包装成长期经营预测，也不代表实时销售预测。

## V6 A/B 测试方案

A/B 测试方案生成器根据历史诊断结果生成实验设计，而不是生成实验结论。输出内容包括：

- 实验目标。
- 实验假设。
- A/B 分组。
- 核心指标和护栏指标。
- 观察周期。
- 样本分流方式。
- 成功判定标准。
- 风险控制。

如果用户问“针对浏览到加购流失高设计一个 A/B 测试方案”，系统可以用历史漏斗数据作为基线，但必须说明实验尚未执行，不能声称已经完成真实线上实验。
