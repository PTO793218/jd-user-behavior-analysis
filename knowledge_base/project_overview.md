# 项目概览

## 项目定位

本项目是一个面向电商运营场景的京东用户行为分析 Agent。它基于已经清洗完成的用户行为数据、RFM 用户分层结果、评论词频结果和评论语义分析结果，提供自然语言问数、指标解释、图表展示和运营建议生成能力。

Agent 的核心意义是降低业务分析门槛。运营人员不需要直接阅读 notebook、编写 SQL 或手动筛选 CSV，可以用自然语言提出业务问题，例如“为什么浏览量高但购买少”“哪个时段适合做促销”“负面评论主要集中在哪些方面”，系统会调用对应的本地分析工具，基于真实数据返回结论。

## 数据范围

当前主分析数据来自 `jd_analysis_final.csv`，覆盖时间为 2024-05-29 至 2024-06-04。

核心规模如下：

- 行为记录数：757,554 条。
- 用户数：10,739。
- 商品数：327,582。
- 商品类目数：5,357。
- RFM 分层用户数：6,108。

行为类型包括：

- `pv`：浏览，679,668 条。
- `cart`：加购，42,714 条。
- `fav`：收藏，20,601 条。
- `buy`：购买，14,571 条。

## 当前版本能力

第一版实现了结构化数据问数能力。系统将数据概览、行为漏斗、RFM 分层、时段趋势、地区销售、设备转化和评论关键词封装为固定工具函数，用户提问后由 Agent 选择工具并生成回答。

第二版新增评论语义级分析能力。系统在 API 预算限制下，对 960 条去重评论样本调用 DeepSeek/OpenAI-compatible API，生成情感分类、情感分数、方面标签和负面原因归因，并保存为 `comment_semantic_result.csv` 和 `semantic_summary.csv`。

第三版计划新增 RAG 能力。RAG 不用于查询 75 万行行为数据，而用于回答项目背景、字段含义、指标定义、语义分析口径和运营策略等知识型问题。

## 使用边界

本项目不是通用聊天机器人，也不是全自动经营决策系统。它的回答必须基于两类依据：

1. 本地结构化数据工具的计算结果。
2. 本地知识库文档中的项目说明和指标口径。

如果问题超出当前数据或知识库范围，例如预测未来销量、查询实时京东价格、分析未收集的用户画像，系统应明确说明当前数据无法判断，不应编造结论。
